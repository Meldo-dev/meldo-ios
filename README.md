> 🇩🇪 Meldo ist ein kostenloser Schulplaner für Schülerinnen und Schüler: Meldungen zählen, Stundenplan (optional aus WebUntis), Noten nach 1–6 oder 0–15 Punkten, Hausaufgaben und Klausuren. Alle Daten bleiben auf deinem Gerät.

## Features

- **Count hand-raises in one tap:** in the app, from a widget or Control Center. After each lesson Meldo asks once, for schools where phones stay in the bag.
- **Timetable:** enter it yourself or import it from your school's WebUntis server, with substitutions, cancellations and room changes. Live Activity / Live Update for the running lesson.
- **Grades:** averages per subject on the German 1–6 or 0–15 point scale, with your school's weighting and rounding rules as configuration.
- **Homework and exams:** reminders, exam calendar, worksheet scanning to PDF, optional import of Microsoft Teams assignments, excuse notes.
- **Private by design:** everything lives on the device. An optional backup and sync goes to *your own* Google Drive, encrypted on the device first (AES-256-GCM, PBKDF2-SHA256 with 600,000 rounds). Meldo has no server.
- **German and English**, light and dark.

## How it's built

```
MeldePlanner/        SwiftUI app (iOS 26, Liquid Glass): App, Data, DesignSystem, Navigation, Features
MeldeWidgets/        Widgets, Live Activity, Control Center button
Shared/              Models, store, engine and intents shared by the app and the widgets
MeldeCore/           Swift package wrapping the Rust core (generated bindings + XCFramework)
core/                meldo-core as a git submodule: Rust crates and the shared string catalog
MeldePlannerTests/   Unit tests (Swift Testing)
MeldePlannerUITests/ UI walk-through and App Store screenshots
scripts/, tools/     Build helpers, icon and store-screenshot renderers
```

The grade math, timetable derivation, WebUntis parsing and statistics are written once in Rust ([meldo-core](https://github.com/meldo-dev/meldo-core)) and shared with the Android app. The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.

## Building (macOS with Xcode 26)

```bash
git clone --recurse-submodules https://github.com/meldo-dev/meldo-ios.git
```

```bash
cd meldo-ios && bash scripts/setup-mac.sh
```

The script checks Xcode, Homebrew, XcodeGen and Rust, builds the Rust core for iOS, generates `MeldePlanner.xcodeproj` and opens it. Set `MELDE_TEAM_ID` to your Apple team ID to run on a device. After pulling core changes, run `git submodule update` and `bash scripts/build-rust-ios.sh`.

### Google Drive and Teams (optional)

OAuth client IDs are not in the repository. Without them the app builds and runs, just without Drive backup and Teams import. To enable them with your own Google Cloud / Azure apps, copy `Config/Secrets.example.xcconfig` to `Config/Secrets.xcconfig` and fill in the IDs.

## Contributing

Issues and pull requests are welcome. Please:

- keep every user-facing string localized in German and English (`core/l10n/Localizable.xcstrings`; `python3 scripts/check_strings.py` checks it),
- run the unit tests for what you touched,
- never commit secrets, keys or client IDs.
